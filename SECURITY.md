# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.

Please do not disclose security vulnerabilities through public GitHub Issues or Pull Requests.

You can report vulnerabilities using GitHub's **Private Vulnerability Reporting** feature, if enabled for this repository.

If private reporting is unavailable, please contact the maintainer by email:

`linakichi.linux@gmail.com`

## Scope

This project provides packaging templates and related files for building Mozc-UT packages on Void Linux.

Security reports concerning this repository's packaging scripts, build configuration, patches, or distributed package artifacts are welcome.

Issues in upstream Mozc or its dictionary sources should also be reported to their respective maintainers where appropriate.

## Response

This is a personal project maintained on a best-effort basis.

I will review reported issues and make reasonable efforts to investigate and address confirmed vulnerabilities. However, response and resolution times are not guaranteed.
